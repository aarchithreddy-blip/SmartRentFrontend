# Smart Rental India — Frontend

React + Vite interface with tenant/owner registration, JWT login, property search, and owner dashboard.
Location selector includes all 28 Indian states and 8 Union Territories, with example city suggestions. Currency is INR.

```bash
npm install
copy .env.example .env
npm run dev
```

Set `VITE_API_BASE_URL=http://localhost:8080/api` locally and to your deployed Render API URL in Vercel.
